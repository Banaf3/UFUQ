# UFUQ

UFUQ is a planned browser-based 3D celestial simulator and intelligent tutoring system for learning how to identify Banat Na'sh and Dhat al-Kursi, locate Al-Jady/Polaris, estimate True North, and derive the Qibla direction.

## Current status

This repository is in the architecture and validation-planning stage. It contains no
product source code, package manifest, or database migration. The independent review is
complete and its verdict is **not ready for application scaffolding**; see
[Architecture Review](docs/ARCHITECTURE_REVIEW.md). The next authorized work is Phase
0 decision/ExecPlan preparation. Application implementation remains blocked on the
needed-by-phase items in [Open Questions](docs/OPEN_QUESTIONS.md), required
[Report Deviations](docs/REPORT_DEVIATIONS.md), ADR approval, and an approved phase
ExecPlan.

## Architecture at a glance

The proposed solution is a TypeScript modular monolith: a React/React Three Fiber browser application, an Express-compatible API, MySQL/InnoDB persistence, and pure framework-free packages for astronomy, assessment, BKT, and adaptive policy. The server owns scoring and mastery transitions. A small, versioned JSON catalogue is generated by a reproducible pipeline rather than manually transcribed.

After Phase 0 and an approved Phase 1 ExecPlan, the recommended first implementation
phase is a local, non-participant evidence-producing vertical slice: an immutable
approved scenario and provenance-built star data through rendering, raw spatial
response, server scoring, one fingerprinted/revision-safe atomic model decision, and the
next scaffold. Full authentication and dashboards follow; a build gate prevents the
fixture identity from entering production.
